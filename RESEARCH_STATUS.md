# Research Status

ChromoVM is currently published as a **research and protocol-design proposal**.

There is no active production implementation associated with this repository at this time. The purpose of this repository is to preserve and publicly communicate the architecture described in **ChromoVM Technical Whitepaper v0.1 (August 2026)**.

The canonical technical claims are those contained in the PDF under `whitepaper/`.

Future implementations, experiments, revisions, or protocol versions—if any—should be published separately and should not silently alter the historical v0.1 artifact.
